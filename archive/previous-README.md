# 이전 버전 README (기록 보존용 · 현재 구성은 루트 README.md 참고)

현재 최종 홈페이지는 `index.html`입니다. 브라우저로 열면 별도 설치 없이 작동합니다.

## 최종 구성

- T-CARE 시안: 사안 작성, 심각도 선택, 지원·복귀의 연속적인 사용 흐름
- 교원안심지원 시안: 안내 중심의 탐색, 자료실과 긴급·공식 상담 경로
- React 시안: 사건 현황, 케이스매니저 협업, 재발관리와 14단계 사건 흐름 체험
- 정책 보고서: 5단계 여정, 3단계 차등지원, 교원 주도 복귀, 장기 사후관리

최종 파일은 `index.html`, `final.css`, `policy-data.js`, `final.js`, `favicon.svg`입니다.
기존 `index.html`의 T-CARE 버전은 `tcare_original.html`로 보존했습니다.
`jaewon_index.html`, `asdf.jsx`, 기존 `style.css`와 `app.js`, `보고서 정보.md`도 보존했습니다.

## 제공 기능과 범위

8개 메뉴, 사안 작성·필수값 검증, 상황별 지원 경로, 사건번호와 지원 선택 연결,
복귀설계서, 예방·사후관리 체크리스트, 재발 시나리오, 자료 검색·분류,
TXT 다운로드, 예시 평가지표, 모바일 메뉴와 글자 확대를 제공합니다.

입력 내용은 현재 페이지의 메모리에서만 유지됩니다. 메뉴 이동 시 보존되며 새로고침하면 초기화됩니다.
실제 기관 전송·신고 접수·상담 예약·관리자 알림·개인정보 저장·첨부파일 업로드 기능은 없습니다.
화면과 다운로드 자료에 체험판 및 제안 정책임을 표시합니다. 법령·공식 정책·상담번호는 원문 링크를 제공합니다.

## 개발·검증

실행만 할 경우 Node.js나 npm은 필요 없습니다. 개발용 명령은 Node.js 환경에서 사용합니다.

```sh
npm install
npm test
npm run build
npm run dev
```

`npm run dev`는 `http://127.0.0.1:4173`에서 최종 파일만 제공합니다.
`npm run build`는 배포할 정적 파일 5개를 `dist/`에 생성합니다.
테스트는 DOM 환경에서 경로 전환, 필수값·입력 안전 처리, 사안→지원→복귀 연결,
다운로드, 검색과 사건 흐름 체험을 검증합니다. 실제 브라우저 화면 검사는 별도입니다.

## 최초 시안 설명 (보존)

교육정책 5팀 PDF의 정책 설계를 바탕으로 만든 정적 웹사이트 프로토타입입니다.

## 파일
- `index.html` : 페이지 구조/콘텐츠
- `style.css` : 반응형 디자인
- `app.js` : 단계별 탭, 5단계 사이클 상세, 모달, 지원경로 데모 등 인터랙션

## 실행
`index.html`을 브라우저에서 더블클릭하면 됩니다. 외부 서버나 빌드 도구가 필요 없습니다.

## 반영한 핵심 정책
- 사전예방 → 사안발생 → 법률/심리/행정지원 → 학교복귀 → 재발방지 5단계 사이클
- 교권침해 심각도 1~3단계 대응 체계
- 통합 사건번호 + 케이스매니저 원스톱 사례관리
- 치료비·상담비 + 교권침해보험/교원보호공제 지원
- 학기 중반 각 1회 실태조사(연 2회) 및 사전예방 모니터링
- 복귀 전 2~4주, 복귀 후 3개월 이내 단계적 복귀 지원
- 재발 위험도 평가 → 3~6개월 사후관리 → 재발 시 기관 중심 강화 대응
- 정책평가 대시보드(초기대응 시간, 전담인력 배정, 지원 연계, 보호 체감, 복귀, 재침해)

## 주의
과제·발표용 정책 프로토타입으로 실제 신고, 상담, 보험 청구, 개인정보 저장 기능은 없습니다.
