# T-Care — 교원 통합지원

`보고서 정보.md`를 바탕으로 완성한 교육정책 5팀의 정책 제안 체험 홈페이지입니다.
흰색 바탕, 녹색 포인트, 번호형 지원 목차와 반응형 레이아웃을 사용합니다.

## 열기

`index.html`을 브라우저에서 열면 서버나 설치 없이 사용할 수 있습니다.
개발용 미리보기는 `npm run dev` 실행 후 http://127.0.0.1:4173 에서 확인합니다.
Windows PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd run dev`를 사용하세요.

## 파일 구성

- `index.html`: 홈페이지 시작점과 공통 메뉴
- `assets/site.css`: 전체 디자인·반응형·접근성 스타일
- `assets/app.js`: 8개 화면과 입력·검색·다운로드·체험 기능
- `assets/policy-data.js`: 지원 단계·자료·정책 제안 데이터
- `보고서 정보.md`: 제공받은 보고서 원문, 수정하지 않음
- `docs/content-map.md`: 보고서와 홈페이지의 내용 대응·보완 사항
- `archive/`: 이전 HTML용 코드, React 시안, 누적 스타일과 README 보관
- `scripts/`: 미리보기·정적 빌드·게시 준비
- `tests/`: 주요 사용자 흐름 회귀검증
- `dist/`: 빌드된 홈페이지

## 완성된 기능

지원 홈, 사전예방, 사안 작성·진단, 법률·심리·행정지원, 학교복귀,
재발방지, 정책 안내·평가지표, 자료실·지원기관의 8개 화면을 제공합니다.

5단계 지원 탐색, 사안 기록과 심각도별 지원 비교, 동일 체험 사건번호로
이어지는 지원 계획, 실시간 복귀설계서, 위험도별 사후관리, 14단계 가상
사건 체험, 자료 검색·분류, TXT 다운로드를 사용할 수 있습니다.
모바일 메뉴, 글자 확대, 키보드 조작, 동작 줄이기 설정, 인쇄도 지원합니다.

## 데이터 범위

과제·발표를 위한 정책 제안 체험입니다. 실제 기관의 신고 접수·상담 예약·
비용 지급·파일 업로드 기능은 없습니다. 입력 내용은 열린 페이지의 메모리에만
유지되며, 새로고침하면 초기화됩니다. 필요한 초안은 TXT로 내려받으세요.

정책 안내의 ‘보고서 근거’는 원문에 기반한 분석 및 출처를 표시합니다.
‘평가지표 예시’의 수치는 실제 성과가 아닌 가상 예시로 구분합니다.
실제 지원은 관할 기관에 확인하며 교권 상담은 지역번호 + 1395입니다.

## 개발 및 확인

```sh
npm install
npm test
npm run build
npm run dev
```

Node.js 24 환경에서 확인했습니다. 추가 런타임 의존성은 없습니다.
테스트는 jsdom에서 경로, 입력 검증, 지원·복귀 연결, 입력 안전 처리,
검색·자료·체험, 보고서 근거, 변경 후 상태 초기화를 검증합니다.
실제 브라우저의 픽셀·레이아웃 검사는 포함하지 않습니다.

`scripts/public-files.cjs`의 허용 목록만 미리보기 및 배포에 포함됩니다.
원본 보고서, 보관 시안, 테스트, 저장소 정보는 웹에서 제공하지 않습니다.
`.site-publish/current/`는 원래 Git 이력을 건드리지 않는 게시용 복사본입니다.
