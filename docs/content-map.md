# 보고서 내용 대응표

기준 원문: 루트의 `보고서 정보.md` (원문 보존).
홈페이지 제목은 기존 통합 버전의 T-Care를 유지했습니다.

| 보고서 | 홈페이지 반영 |
| --- | --- |
| 0. 정의 | 정책 안내 → 보고서 근거의 개념 설명·법령 원문 |
| 1. 주제·현황·킹던 모형 | 보고서 근거의 조사 수치 및 문제·정책·정치 흐름 |
| 2. 기존 정책 분석 | 교보위·보호센터·공제 및 보험의 역할과 보고서가 제기한 공백 |
| 3~4. 문제 및 정책목표 | 개입 시점·지원 접근성·연계성의 문제와 개선 방향 일대일 대응 |
| 5. 대안 | 홈의 사전예방 → 사안발생 → 통합지원 → 학교복귀 → 재발방지 |
| 6. 사안발생 | 기록·안전 확보, 심각도 1~3단계, 대응 주체와 지원 비교 |
| 6. 법률·심리·행정지원 | 1단계 기록·관찰, 2단계 초기상담·간이 담당자, 3단계 전담지원 |
| 6. 학교복귀 | 교사 주도 설계, 복귀 전 2~4주, 복귀 후 1개월·3개월, 선택·보류권 |
| 6. 재발방지 | 종결 직후 위험 평가 → 기본 3개월·고위험 6개월 이상 관리 → 기관 중심 대응 |
| 7. 평가 | 초기 대응시간·인력 배정·지원 연계·보호 체감·복귀·재침해 지표 |
| 8. 기대효과 | 업무 부담 감소, 회복·복귀의 연속성, 교원 이탈 예방 (향후 검증) |

## 사실·정책 제안·화면 예시 구분

- 2024학년도 교보위 4,234건, 학생 생활지도 불응·방해 32.4%, 보호자 등의
  반복·부당 간섭 24.4%는 교육부 2025년 5월 13일 발표에 따른 값입니다.
  [공식 출처](https://www.korea.kr/news/policyNewsView.do?newsId=148943122)
- 2026년 1월 22일 교육부 대책은 발표 당시의 정책 기반으로 소개합니다.
  향후 계획이나 법률 개정안을 이미 시행된 제도라고 표시하지 않습니다.
  [공식 출처](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=105198&lev=0&m=020402&opType=N&s=moe&statusYN=W)
- 보고서의 79.6% 설문, ‘5법 시행 1년’이라는 표현, 드라마·선거 관련 세부 주장은
  확인 가능한 원문 근거와 시점 정합성이 부족해 홈페이지의 확정 사실에서 제외했습니다.
- 원문의 3,925건·93.0%는 나눗셈 기준 약 92.7%로 서로 맞지 않아 핵심 통계로
  채택하지 않았습니다. 발표문에서 확인된 개최 건수와 유형 비중만 사용합니다.
- 공적 교원보호공제와 개인 민간보험을 같은 제도로 취급하거나, 모든 보호센터의
  지원이 교보위 의결 이후에만 가능하다고 일반화하지 않습니다.
- 3단계 차등지원과 동일 사건번호·케이스매니저, 복귀·사후관리 일정은 보고서의
  정책 설계입니다. 현행 제도의 일률적인 지원 보장으로 안내하지 않습니다.
- 보고서에 수업계획서 본문은 없습니다. 기존 시안의 40분 예방수업과 학기 중반
  연 2회 점검은 화면 구현용 보완 예시로 구분하며 공식 확정 일정이 아닙니다.
- 2.4시간·90%·88%·4.2/5·81%·6%, 예시 128건 등 평가 화면은 가상 데이터입니다.
  실제 조사 수치나 사용자 입력 집계가 아닙니다.
- 상담번호는 소속 교육청의 지역번호 + 1395로 안내합니다.
  [인천교육청 공식 안내 예시](https://www.ice.go.kr/ice/na/ntt/selectNttInfo.do?mi=11822&nttSn=3369375)

## 구현과 검증 범위

체험 기록, 지원 선택, 복귀 계획은 현재 페이지의 메모리에서 연결됩니다.
수정된 사안을 제출하면 이전 진단·지원·복귀·사후관리 결과를 초기화합니다.
자동저장이나 외부 전송은 하지 않으며 실제 개인정보를 요구하지 않습니다.
정책 제안의 ‘연계 의무’와 교원의 상담·복귀 프로그램 자기결정권을 구분합니다.
